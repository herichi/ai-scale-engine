# AI Scale Engine — Conversion Engine

**Status: APPROVED — locked as project knowledge (2026-07-26).**

This defines the lead magnet and the short path from first touch to the
core CTA. Use alongside `offer.md` (the 4-stage funnel) and `brand-voice.md`
(voice/tone) when writing any capture asset, DM sequence, or CTA copy.

---

## LEAD MAGNET

**Format:** Written guide/checklist (PDF).

**The win:** Someone who finishes it and does what it says has published
**one real piece of content using the system, start to finish** — a
tangible, finished output, not just theory or time saved. This is the proof
point that the system actually works, before anyone pays anything.

**How they get it:** Not decided yet — see Module 2.

---

## THE PATH

Twin video → lead magnet (PDF, capture) → *(no warm-up step)* → **core CTA**

- **Warm-up value between magnet and CTA:** None — goes straight from lead
  magnet delivery to the core CTA, no email/DM warm-up sequence.
- **Optional value-before-CTA asset:** None — the lead magnet is the only
  asset before the ask.
- **Core CTA (reused from `offer.md` Stage 4, not reinvented):**
  > "Join the AI Scale Engine — link in bio. $29/month."

No booked-call step anywhere in this path (confirmed: not part of the
funnel).
