# BRAND_KIT — TEMPLATE

Copy this into your own project as `BRAND_KIT.md` and fill in every
`[bracketed]` value with your own. This is a source-of-truth file for any
carousel, overlay, or video generation that needs your brand's visual or
legal identity — colors, typography, logo, templates, and policy text.
`brand-voice.md` covers how your brand talks; this file covers how it
looks and what it's allowed to promise.

**Filling this in by hand?** Keep reading. **Prefer Claude to walk you
through it step by step, with an upload widget for each asset?** Use
[`BRAND_KIT-intake-prompt.md`](BRAND_KIT-intake-prompt.md) instead — a
copy/paste prompt that builds this file for you interactively.

## Why this file exists

Same "define once, reuse everywhere" principle as your `AVATAR_LOCK.md`
and `VOICE_LOCK.md` — once this is filled in, every future carousel or
video request automatically uses your real brand look instead of a
generic default or repeated re-explaining.
