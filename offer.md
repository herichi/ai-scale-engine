# AI Scale Engine — Funnel Map & Offer

**Status: APPROVED — locked as project knowledge (2026-07-26).**

This is the operational funnel reference for AI Scale Engine. It defines the
one path every piece of content should move a lead through: Hook → Interest →
Consideration → Action. Use this alongside `brand-voice.md` when writing any
post, script, or ad — the funnel stage tells you the JOB of the content; the
brand voice tells you HOW to say it.

---

## STAGE 1 — HOOK (the pain called out)

**Pain:** Growth is capped — more clients means more hours, and there aren't
more hours. Income is tied 1:1 to hours worked, so scaling clients just means
working more, not earning more freedom.

**Bold message:**
> "More clients shouldn't mean more hours. If it does, you don't have a business — you have a ceiling."

---

## STAGE 2 — INTEREST (the free value given)

**Free value:** A free guide or checklist that lets them install ONE real
piece of the AI content system themselves — not a demo, not theory, an
actual working piece of the engine. This proves the system works before
anyone pays anything.

**Bold message:**
> "Here's one piece of the system. Install it today, free. Then decide if you want the rest built for you."

---

## STAGE 3 — CONSIDERATION (the fear handled + proof)

**Fear:** "This is too technical / complex for me to set up."

**Proof/method:** Mohamed is proof it's simple — he built the entire AI
Scale Engine himself, starting with zero coding background, from the exact
same overwhelm his audience feels right now. He's not the expert who never
struggled; he's the case study that someone with no technical background can
do this.

**Bold message:**
> "I built this with zero coding background. If I could figure it out, so can you — or I'll just build it for you."

---

## STAGE 4 — ACTION (the ONE call-to-action)

**CTA:** Join the AI Scale Engine community. **$29/month**, founding-member
pricing. Self-build path — this is the single CTA every piece of content
points to.

**Bold message:**
> "Join the AI Scale Engine — link in bio. $29/month."

**Note:** This CTA is deliberately single-path (self-build only), not the
"build it yourself, or let us build it for you" fork used elsewhere in the
brand voice's CTA/selling-style sections. The $499 done-for-you tier still
exists as an offer (see below) but is NOT the funnel's primary CTA — it's a
secondary path for leads who want it built for them, surfaced separately
(e.g. the website's "We build it for you" section), not the main funnel
driver.

---

## THE OFFER (reference)

- **Self-build tier (primary funnel CTA):** Skool community (courses +
  community) + one 1:1 implementation session included. **$29/month**
  founding-member pricing.
- **Done-for-you tier (secondary offer, not the funnel CTA):** full setup
  built by the team. **$499** one-time. Booking:
  `https://calendly.com/contact-aiscale-engine/30min`.
